# Contributing

Please read the project architecture and data contribution documentation before changing language data or domain behavior.

## Licensing requirement

This project is licensed under GNU AGPL-3.0-only. By contributing code, you agree that your contribution is made available under that license. If you deploy a modified version for users over a network, you must offer those users the corresponding source code, including your modifications and the applicable installation information required by the AGPL.

Every pull request should describe what changed, why it changed, how it was tested, and what source or evidence supports language-data changes.
