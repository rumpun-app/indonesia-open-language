The AGPL is intentional: improvements must remain available to the community even when the software is operated as a network service. A modified deployment must provide users with access to the corresponding source code under the same license terms.

Language datasets, recordings, and third-party materials may have separate licenses. Each source and media record must retain its own license and attribution metadata. The repository license does not override a third party's more restrictive or incompatible terms.

Before adding a dependency or dataset, confirm license compatibility and record the applicable attribution in the relevant package or data documentation.
